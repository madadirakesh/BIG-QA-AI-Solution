REQUIREMENTS:
User Story: Inward bulk case Attach spreadsheet manual process
Acceptance Criteria:
GIVEN: The bulk case is created successfully in last user story
WHEN: User searches for created bulk case using case id
THEN: User will see the bulk case details displayed in review mode and in the assignment sees attach spreadsheet with begin

GIVEN: The bulk case entry is created successfully in last user story
WHEN: User navigated to work queue where the bulk case is routed in previous user story
THEN: System will open the case and user will see the bulk case details in review mode and in the assignment sees attach spreadsheet with begin

GIVEN: User clicks on begin
WHEN: User navigated to attach a spreadsheet screen
THEN: User will see the following on attach spreadsheet screen
bulk case entry ID
status = new
attach a spreadsheet label
file description free textbox with max 56 chars
file label
choose file button next to file label followed by a message "No file chosen until the file is selected"
finish and cancel buttons

GIVEN: User has navigated to attach spreadsheet screen
WHEN: user adds the file descriptions > 56 chars and uploads inwards file and clicks on finish button
THEN: User should see the error message on the screen

GIVEN: User has navigated to attach spreadsheet screen
WHEN: User fills file description < 56 chars and clicks on choose file button
THEN: A window file selection popup will be displayed to select the file

GIVEN: User has filled file description and clicked on choose file
WHEN: User sees file selection popup and selects a file
THEN: User will be able to select only one file at a time and will only be allowed to select xlsx file format

GIVEN: User has filled file description and clicked on choose file
WHEN: User sees file selection popup and selects a xlsx file
THEN: System attaches the xlsx file and user should be able to see the attached file name after the choose file

GIVEN: User is navigated to attach spreadsheet screen
WHEN: User has clicked on finish button without attaching file
THEN: System will display error message

GIVEN: User attached the file
WHEN: User clicks on finish button
THEN: System will proceed to decrypt the uploaded file and system logs audit for the same

GIVEN: User attached the file
WHEN: User again selects another file to attach
THEN: System will replace the latest file as attachment
 

GIVEN: Unauthorized user which access group is not equal to project logged into system successfully.
WHEN: User searches for the created bulk case or navigated to open the case from the work queue where the case was routed and clicks on case id and begin
THEN: System should restrict unauthorized user to access with flow actions.
